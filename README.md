# Smart StreetLight Medical Project

A smart infrastructure and health-monitoring integration project designed to combine automated street lighting systems with medical support features.

## 🚀 Features
- *Smart Automation:* Efficient control mechanism for street lights.
- *Medical Integration:* Built-in features to assist with emergency health responses or data logging.
- *Python-based Backend:* Clean and modular code architecture.

## 🛠️ Tech Stack
- *Language:* Python (model.py)
- *Environment:* Streamlit / Local Server (as applicable)

## 📁 Project Structure
- model.py - Core logic and backend model file.
- requirement.txt - Lists all required Python dependencies and libraries.
